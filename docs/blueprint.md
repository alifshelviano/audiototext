# **App Name**: AudioScribe AI

## Core Features:

- Audio Recording: Record audio directly within the application.
- Audio Upload: Upload pre-recorded audio files (MP3, WAV, etc.) for transcription and summarization.
- Transcription via ElevenLabs: Transcribe the recorded audio into text using the ElevenLabs API (API Key: sk_c2e70bd2315899aa49a41a6faf0e0dfd4fe2c49092bafdc4).
- AI Summarization: Analyze the transcribed text with Gemini to generate a concise summary.
- Speaker Detection: Use AI tool to identify and differentiate between speakers in the audio.
- Summary Display: Display the generated summary in a clean, readable format, highlighting key topics.
- Edit summary: Give user options to correct parts of summary

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) to convey calmness and focus, aiding concentration during audio analysis.
- Background color: Light gray (#F0F0F0) to ensure comfortable readability and reduce eye strain.
- Accent color: Deep blue (#3F72AF) to highlight key elements such as call-to-action buttons and important information.
- Font: 'Inter' sans-serif for a clean, modern and readable interface; suitable for both headings and body text.
- Use minimalist icons to represent functionalities like record, upload, and summarize.
- Maintain a clean and intuitive layout, prioritizing the audio controls and summary display area.
- Use subtle animations to indicate loading and processing states, providing user feedback without being distracting.
